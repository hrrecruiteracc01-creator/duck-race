# 🦆 鸭鸭狂按大赛：独立网站版

大屏幕投影跑道，参加者用手机扫码、输入名字就能加入，不需要任何账号。比赛开始后狂按手机上的按钮，按得越快鸭子游得越快，最先冲线的前几名中奖。

- **大屏幕（主持人）**：`你的网址/host`
- **手机（参加者）**：`你的网址/`（大屏幕上会自动显示这个二维码）

---

## 方法一：部署到 Render（免费，推荐）

全程只需要网页操作，大约 10 分钟。

### 1. 把代码放上 GitHub
1. 注册或登录 [github.com](https://github.com)。
2. 右上角 **+** → **New repository**，名字填 `duck-race`，选 **Public**，点 **Create repository**。
3. 在新仓库页面点 **uploading an existing file**，把这个文件夹里的**所有文件**拖进去（`server.js`、`package.json`、`README.md` 和整个 `public` 文件夹）。不要上传 `node_modules`。
4. 点 **Commit changes**。

### 2. 在 Render 上开网站
1. 用 GitHub 账号登录 [render.com](https://render.com)。
2. 点 **New +** → **Web Service** → 选你的 `duck-race` 仓库。
3. 按下面填写：
   - **Runtime**：Node
   - **Build Command**：`npm install`
   - **Start Command**：`npm start`
   - **Instance Type**：Free
4. （可选，建议）展开 **Environment Variables**，加一项 `HOST_KEY` = 你自己定的密码，例如 `abc123`。
   设了密码以后，大屏幕要用 `https://你的网址/host?key=abc123` 打开，参加者就没办法乱开主持人画面。
5. 点 **Create Web Service**，等几分钟出现 **Live** 就完成了。网址类似 `https://duck-race-xxxx.onrender.com`。

### ⚠️ 活动当天注意
- Render 免费版**闲置 15 分钟会自动休眠**，第一次打开要等大约 1 分钟。请在活动开始前 5 到 10 分钟先打开大屏幕页面，把它“叫醒”。
- 大屏幕页面开着时，网站会一直保持在线。
- **只开一个大屏幕画面**。如果在另一台电脑打开 `/host`，新的画面会接管比赛。

## 方法二：在自己的电脑上运行（同一个 WiFi）

适合测试，或者场地网络允许手机和电脑互相连接的时候使用。

1. 安装 [Node.js](https://nodejs.org)（LTS 版本）。
2. 在这个文件夹里打开终端，输入：
   ```
   npm install
   npm start
   ```
3. 大屏幕打开 `http://localhost:3000/host`。
4. 找到电脑的局域网 IP（例如 `192.168.1.23`），手机连同一个 WiFi 后打开 `http://192.168.1.23:3000`。
   这时二维码需要显示局域网地址，所以要用 `http://192.168.1.23:3000/host` 打开大屏幕。

> 很多公司和酒店的 WiFi 会阻止设备之间互相连接。遇到这种情况请用方法一。

## 玩法与设置（在大屏幕大厅里调整）

| 设置 | 说明 |
|---|---|
| 中奖名额 | 最先冲线的前几名中奖（1 到 20） |
| 赛道长度 | 短、中、长，分别约 15、25、40 秒（以每秒按 8 下计算） |
| 运气成分 | 0% 表示完全比手速；越高，随机加减速和“⚡ 加速”越多，手慢的人也有机会赢 |
| 已中奖的人下一轮不参加 | 适合分多轮抽奖，中奖者手机会显示“你已中奖，请观战” |
| +10 只测试鸭 | 没有真人时先试玩，正式开始前记得按“清除测试鸭” |
| 清空中奖名单 | 重新开始整场活动 |

**防作弊**：每人每秒最多计算 14 下，用连点器也不会更快。

**断线**：手机断线后重新打开同一个网址，会自动回到原本的鸭子，名字和进度都会保留。

**人数**：已用 100 部模拟手机同时比赛测试过。
